# Notebooks

Use notebooks for exploratory data analysis, sanity checks, visualization, and presentation-oriented analysis.

Reusable project logic should be moved into `src/` so experiments do not depend on hidden notebook state.

Suggested naming convention:

- `01_dataset_audit.ipynb`
- `02_data_sanity_checks.ipynb`
- `03_baseline_results.ipynb`
- `04_cross_dataset_analysis.ipynb`
